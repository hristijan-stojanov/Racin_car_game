# Racin car game

A 2D racing game developed as a student project for the Visual Programming course. The game is inspired by classic arcade racing games and allows players to control a car, avoid obstacles, and compete to reach the finish line.

![slika 1](images/image1.PNG)


## Features
  - Real-time car movement and collision detection.
  - Dynamic spawning of opponent vehicles.
  - Life system with game over logic.
  - Player name input before starting the game.
  - Restart and exit options after game over.
## Controls
- Left Arrow – Move car left
- Right Arrow – Move car right
- R – Restart game after losing
- C – Exit the game
  
## Technologies Used
- C#
- Windows Forms (.NET Framework)
- Object-Oriented Programming principles
